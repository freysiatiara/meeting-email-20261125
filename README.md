`main.py` (Python standard library only) writes a single line of plain text — one joke about a meeting that should have been an email — to `entry.txt`, with no trailing newline.

## Run it

```sh
python3 main.py
```

The output path is resolved as `ENTRY_OUTPUT`, else `OUTPUT_DIR` / `MAKEFUN_OUTPUT_DIR` + `entry.txt`, else `/output/entry.txt` when that directory exists, else `entry.txt` next to the script.
